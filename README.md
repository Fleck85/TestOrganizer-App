# TestOrganizer-App

[App öffnen und auf dem Tablet installieren](https://fleck85.github.io/TestOrganizer-App/)

Allgemeine Offline-App mit ausschließlich synthetischen Beispielaufgaben. Eigene Vorlagen werden lokal importiert. Keine Originaltestunterlagen, privaten Vorlagen, Backups oder Testdurchläufe sind Bestandteil dieser Veröffentlichung.

Android: Link in Chrome öffnen → „App installieren“. iPad: Link in Safari öffnen → Teilen → „Zum Home-Bildschirm“. Zunächst online vollständig laden und „Offline-Bereitschaft prüfen“ wählen. Danach steht die App einschließlich PDF-Erstellung offline zur Verfügung. Installation und physischer Druck sind am jeweiligen Gerät zu prüfen.

Vorlagen und gespeicherte Tests bleiben in diesem Browser auf diesem Gerät. Regelmäßig lokale Backups exportieren. Persönliche Stammdaten bleiben nur bis zum Schließen/Neuladen im Arbeitsspeicher. Eine ausdrücklich erzeugte Ergebnis-PDF kann diese Angaben enthalten. Ohne lokal importierte und abgenommene Originaldruckvorlage ist die PDF eine gekennzeichnete Demoausgabe.

Dieses Repository enthält unter `site/` nur die geprüften Build-Dateien sowie Pages-Konfiguration und Prüfsummen. Es übernimmt keine Entwicklungs-Historie. Veröffentlichungen erfolgen ausschließlich durch manuellen Start von `pages.yml` mit `VEROEFFENTLICHEN` und dem vollständig geprüften öffentlichen Commit-SHA. Pushes veröffentlichen nicht automatisch. Updates in der installierten App werden ausdrücklich angewendet, sobald laufende Tests geschlossen und Änderungen gespeichert sind.

Die mitgelieferten Bibliotheks- und Schriftlizenzen befinden sich unter `site/src/vendor/` und `site/src/fonts/`. Für die App selbst wird hier keine zusätzliche Lizenz erteilt.
